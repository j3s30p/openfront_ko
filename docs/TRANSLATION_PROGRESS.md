## 배포 및 적용 기록

- `v0.1.0-rc1`은 설치 스크립트와 Galmuri9를 사용한 시험 배포였음. 사용자 요청에 따라 `rc2`에서 글꼴·CSS·스크립트를 제외함.
- 활성 업데이트의 `lang/ko.json` manifest는 설치 폴더의 `resources/renderer/_assets/lang/ko.a294bb02d6c3.json`을 가리키고, 별도 한국어 오버레이 파일은 없음.
- 설치 폴더에서 한국어 JSON만 수정하고 CSS와 `asset-hashes.json`을 원본으로 복원한 상태에서 게임을 한 번 실행함. OpenFront 프로세스 5개가 실행됐고, 활성 manifest와 한국어 오버레이 부재를 다시 확인함.
- `OpenFront_KoreanPatch_0.1.0-rc2.zip`에는 설치될 게임 파일이 한국어 JSON 하나뿐임. ZIP SHA-256: `ACECD7AE65C61FF29BED9CC7E8ECF561EE905AF001EE905A244F63D60F2CE090`.

`번역 완료`는 데이터 수준의 완료이며, 모든 화면의 글자 잘림 검수가 끝났다는 뜻은 아닙니다. 게임 업데이트로 manifest의 한국어 경로가 바뀌면 새 버전용 패치를 다시 만들어야 합니다.
